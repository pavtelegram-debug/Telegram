# FlostGram starter

Стартовый шаблон бота + workflow сборки Android-клиента. Это не полный клон Telegram и не готовый APK.

## Бот
1. Создай бота через @BotFather.
2. Установи Python 3.11+ и зависимости: `pip install -r requirements.txt`.
3. Задай переменные окружения `BOT_TOKEN` и `ADMIN_IDS` (твой числовой Telegram ID; несколько ID через запятую). `DB_PATH` необязателен.
4. Запусти `python bot/main.py` на хостинге, который поддерживает постоянно работающие процессы.

Не публикуй токен в репозитории. Если токен попал в публичный код, отзови его через BotFather.

Команды: `/start`, `/admin`, `/user ID`, `/ban ID причина`, `/unban ID`, `/label ID scam|fake|hold|major`, `/unlabel ID scam|fake|hold|major`, `/stats`. Блокировка касается только функций этого бота; метки внутренние.

## Android APK
Скопируй `.github/workflows/build-apk.yml` в корень своего форка в такой же путь. В GitHub открой Actions → Build FlostGram APK → Run workflow. APK появится в Artifacts, если сборка успешна. Workflow не переименовывает приложение и не заменяет иконку автоматически: это нужно отдельно внести в ресурсы и имя соответствующего Android flavor.

## Что нужно реализовывать отдельно
- Telegram-аккаунты регистрируются по правилам Telegram; произвольный номер нельзя зарегистрировать только по email.
- Управление чужими аккаунтами, удаление/заморозка аккаунтов и глобальные метки недоступны обычному боту.
- Stars, Premium, подарки, Fragment и Wallet требуют официальных API, доступов и/или платёжных интеграций.
- Поддержка десяти аккаунтов зависит от возможностей клиента и не добавляется одним ботом.

Перед распространением форка соблюдай лицензию исходного проекта и ясно указывай, что клиент неофициальный.
